# 参数输入规范 - 数据库接口文档

##  Required fields（3）

| Field Name         | Type     | Illustrate         | Example Value | Constraint                                                |
|--------------------|----------|--------------------|---------------|-----------------------------------------------------------|
| `biomolecule_name` | `string` | Biomolecule names  | `"lysozyme"`  | 1-100 characters                                          |
| `biomolecule_type` | `string` | Biomolecular types | `"protein"`   | enumerate: `"protein"`, `"peptide"`, `"polysaccharide"`   |
| `property`         | `string` | Experiment type    | `"stability"` | enumerate: `"stability"`, `"solubility"`, `"aggregation"` |

---

##  Experimental parameters（8 options, but at least one must be filled in.）

| Field Name            | Type     | Unit  | Range | Example | Illustrate        |
|-----------------------|----------|-------|---|---|-------------------|
| `pH`                  | `float`  | Unitless   | 0-14 | `7.0` | pH value               |
| `temperature_c`       | `float`  | °C | -20 - 150 | `25.0` | temperature                |
| `concentration_mg_ml` | `float`  | mg/mL | 0.001 - 1000 | `10.0` | biomolecular concentration            |
| `ionic_strength_mM`   | `float`  | mM | 0 - 5000 | `150.0` | Ionic strength              |
| `additive`            | `string` | text    | - | `"glycerol"` | Additive Name    |
| `time_min`            | `float`  | min | 0 - 100000 | `60.0` | Experiment time              |
| `shear_rate_s1`       | `float`  | s⁻¹   | 0 - 10000 | `100.0` | Shear rate              |
| `pressure_bar`        | `float`  | bar   | 0 - 10000 | `1.0` | pressure（1 bar ≈ 1 atm） |

---

## 两种使用场景

### 场景1：参数验证（所有参数已知）
**输入**: 填入所有参数（或大部分参数）  
**输出**: `stable` / `unstable` + 置信度

**JSON示例**:
```json
{
  "biomolecule_name": "lysozyme",
  "biomolecule_type": "protein",
  "property": "stability",
  "pH": 7.0,
  "temperature_c": 25.0,
  "concentration_mg_ml": 10.0,
  "ionic_strength_mM": 150.0,
  "additive": "glycerol",
  "time_min": 60.0,
  "shear_rate_s1": null,
  "pressure_bar": 1.0
}
```

### 场景2：参数推荐（部分参数已知）
**输入**: 填入部分参数 + 需要推荐的参数名称  
**输出**: 推荐参数的范围（IQR统计）

**JSON示例**:
```json
{
  "biomolecule_name": "lysozyme",
  "biomolecule_type": "protein",
  "property": "stability",
  "pH": 7.0,
  "temperature_c": 25.0,
  "recommend_parameters": ["concentration_mg_ml", "ionic_strength_mM"]
}
```
