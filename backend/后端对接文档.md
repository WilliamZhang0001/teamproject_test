## 概述

DoE-Assist 后端提供 RESTful API 接口，支持：
- 用户认证和管理
- 实验条件预测（分类判断和参数推荐）
- 统一预测/参数推荐编排（`/api/v1/predict`）
- 异步批处理任务编排（`/api/v1/jobs`）
- CSV 批量预测上传（`/api/v1/experiments/predict-csv`）
- 文献检索、相似文献查找与增强证据
- 用户实验历史记录

### 核心模块

- **ModelOrchestrator**：统一调度模型预测与 IQR 参数推荐，内置 Prometheus 指标埋点。
- **ParameterSpec/Validator**：从《参数输入规范.md》解析字段约束，对传入参数做统一校验及归一化。
- **RateLimiter & IdempotencyCache**：针对 `/api/v1` 系列接口提供速率限制与幂等性支持。
- **Async Job Store**：内存级任务队列（`/api/v1/jobs`）用于后台异步预测。

### 基础信息

- **API Base URL**: `http://localhost:8000`
- **API文档**: `http://localhost:8000/docs` (Swagger UI)
- **API文档(ReDoc)**: `http://localhost:8000/redoc`
- **异步任务监控**: `/api/v1/jobs/{job_id}`
- **上传目录**: `backend/uploads/`（由 `/api/v1/upload` 自动创建）
- **参数规范**: `参数输入规范.md`（默认路径，可通过 `PARAMETER_SPEC_PATH` 环境变量重写）
- **协议**: HTTP/HTTPS
- **数据格式**: JSON / CSV（批量预测输出）

### 响应格式

所有API响应遵循统一格式：

```json
{
  "status": "success",
  "data": { ... }
}
```

错误响应：

```json
{
  "detail": "错误信息"
}
```

`/api/v1` 前缀的统一预测类接口会返回带有 `error_code`、`message`、`details` 字段的结构化错误。

## 认证机制

### JWT Token 认证

系统使用 JWT (JSON Web Token) 进行用户认证。

### 1. 用户注册

**端点**: `POST /users`

**请求体**:
```json
{
  "username": "testuser",
  "email": "test@example.com",
  "password": "password123"
}
```

**响应** (201 Created):
```json
{
  "id": 1,
  "username": "testuser",
  "email": "test@example.com",
  "role": "user",
  "is_active": true,
  "created_at": "2024-01-01T00:00:00"
}
```

### 2. 用户登录

**端点**: `POST /auth/login`

**请求体**:
```json
{
  "username": "testuser",
  "password": "password123"
}
```

**响应** (200 OK):
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "user": {
    "id": 1,
    "username": "testuser",
    "email": "test@example.com",
    "role": "user",
    "is_active": true,
    "created_at": "2024-01-01T00:00:00",
    "last_login_at": "2024-01-01T12:00:00"
  }
}
```

### 3. 使用Token

在后续请求中，在Header中携带Token：

```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**注意**: 当前版本中，部分端点支持匿名访问（`user_id` 可为 `None`）。

### 4. 速率限制与幂等

- `/api/v1/*` 端点启用速率限制：默认每个用户/Token/IP 每分钟 120 次，超出返回 `429 rate_limited`。
- `POST /api/v1/predict` 支持 `Idempotency-Key` 请求头，用于客户端重试场景缓存结果。
- 所有 `/api/v1` 端点均需要有效 JWT Token。

## API端点详细说明

### 1. 实验条件分类预测

**功能**: 判断输入的实验条件组合是好还是不好

**端点**: `POST /api/v1/experiments/predict-classification`

**请求参数**:
- `top_k` (Query, 可选): 返回最相似的文献数量，默认 3

**请求体**:
```json
{
  "biomolecule_type": "protein",
  "biomolecule_name": "lysozyme",
  "experiment_type": "stability",
  "pH": 7.0,
  "temperature_c": 25.0,
  "concentration_mg_ml": 10.0,
  "ionic_strength_mM": 150.0,
  "additive": "sucrose",
  "time_min": 60.0,
  "shear_rate_s1": 0.0,
  "pressure_bar": 1.0
}
```

**参数说明**:
- `biomolecule_type` (必需): 物质类别，可选值: `"protein"`, `"peptide"`, `"polysaccharide"`
- `biomolecule_name` (必需): 物质名称，如 `"lysozyme"`
- `experiment_type` (可选，默认: `"stability"`): 实验类别，可选值: `"stability"`, `"solubility"`, `"aggregation"`
- 以下8个参数均为可选（可提供任意组合）:
  - `pH`: pH值 (0-14)
  - `temperature_c`: 温度 (°C, -50 到 200)
  - `concentration_mg_ml`: 浓度 (mg/mL, >0)
  - `ionic_strength_mM`: 离子强度 (mM, >=0)
  - `additive`: 添加剂 (字符串)
  - `time_min`: 时间 (分钟, >=0)
  - `shear_rate_s1`: 剪切速率 (s⁻¹, >=0)
  - `pressure_bar`: 压力 (bar, >=0)

**响应** (200 OK):
```json
{
  "status": "success",
  "data": {
    "prediction": "Good",
    "confidence": 0.852,
    "similar_literature": [
      {
        "id": 1234,
        "similarity_score": 0.92,
        "literature": {
          "doi": "10.1234/example",
          "title": "Stability of lysozyme in...",
          "authors": "Smith, J. et al.",
          "pub_year": 2020
        },
        "parameters": {
          "pH": 7.0,
          "temperature_c": 25.0,
          "concentration_mg_ml": 10.0
        },
        "outcome_text": "Lysozyme remained stable...",
        "confidence": 0.85
      }
      // ... 最多返回 top_k 条记录
    ]
  }
}
```

**响应字段说明**:
- `prediction`: 预测结果，`"Good"` 或 `"Bad"`
- `confidence`: 置信度 (0-1)
- `similar_literature`: 最相似的文献列表（按相似度降序）
  - `similarity_score`: 相似度分数 (0-1)
  - `literature`: 文献元信息
  - `parameters`: 实验参数
  - `outcome_text`: 实验结果描述

### 2. 参数值预测

**功能**: 预测指定参数的值

**端点**: `POST /api/v1/experiments/predict-parameter`

**请求体**:
```json
{
  "input": {
    "biomolecule_type": "protein",
    "biomolecule_name": "lysozyme",
    "experiment_type": "stability",
    "pH": 7.0,
    "temperature_c": 25.0
  },
  "predict_parameters": ["concentration_mg_ml", "ionic_strength_mM"],
  "top_k": 3
}
```

**参数说明**:
- `input`: 用户输入的实验条件（格式同分类预测）
- `predict_parameters` (必需): 需要预测的参数列表，可选值:
  - `"pH"`
  - `"temperature_c"`
  - `"concentration_mg_ml"`
  - `"ionic_strength_mM"`
  - `"additive"`
  - `"time_min"`
  - `"shear_rate_s1"`
  - `"pressure_bar"`
- `top_k` (可选，默认: 3): 返回最相似的文献数量

**响应** (200 OK):
```json
{
  "status": "success",
  "data": {
    "predicted_parameters": {
      "concentration_mg_ml": {
        "recommended_value": 10.0,
        "min": 5.0,
        "max": 20.0,
        "median": 10.0
      },
      "ionic_strength_mM": {
        "recommended_value": 150.0,
        "min": 100.0,
        "max": 200.0,
        "median": 150.0
      }
    },
    "confidence": 0.75,
    "similar_literature": [
      {
        "id": 1234,
        "similarity_score": 0.88,
        "literature": { ... },
        "parameters": { ... }
      }
      // ... 最多返回 top_k 条记录
    ]
  }
}
```

**响应字段说明**:
- `predicted_parameters`: 每个参数的预测结果
  - `recommended_value`: 推荐值
  - `min`: 最小值（IQR范围）
  - `max`: 最大值（IQR范围）
  - `median`: 中位数
- `confidence`: 整体置信度 (0-1)
- `similar_literature`: 最相似的文献列表

### 7. 批量CSV预测

**功能**: 上传 CSV 文件批量执行分类或参数预测。

**端点**: `POST /api/v1/experiments/predict-csv`

**表单参数**:
- `file` (必需): CSV 文件，需包含标题行。
- `prediction_type` (可选，默认 `classification`): `classification` 或 `parameter`。
- `top_k` (可选，默认 3): 返回最相似文献数量。
- `column_mapping` (可选): JSON 字符串，自定义字段→列名映射。
- `predict_parameters` (当 `prediction_type=parameter` 时必填): JSON 数组，声明待预测参数。

**默认列映射**:

| 字段 | 默认列名 |
| --- | --- |
| `biomolecule_type` | `Substance Category` |
| `biomolecule_name` | `Substance Name` |
| `property/experiment_type` | `Property` / `Experiment Type` |
| `pH` | `pH` |
| `temperature_c` | `Temperature` |
| `concentration_mg_ml` | `Concentration` |
| `ionic_strength_mM` | `Ion Concentration` |
| 其他可选字段 | `Time`、`Additives`、`Shear Rate`、`Pressure` |

**响应**: 返回 `text/csv` 文件流，自动追加三列：`Result Value`、`Confidence Level`、`Related Literature`（JSON 字符串）。

**错误示例**:

```json
{
  "detail": "predict_parameters is required when prediction_type is 'parameter'"
}
```

### 8. 统一预测/参数推荐

**功能**: 统一入口完成稳定性预测与 IQR 参数推荐。

**端点**: `POST /api/v1/predict`

**请求头**:
- `Authorization: Bearer <token>`（必需）
- `Idempotency-Key`（可选）

**请求体示例**:

```json
{
  "biomolecule_name": "lysozyme",
  "biomolecule_type": "protein",
  "property": "stability",
  "pH": 7.0,
  "temperature_c": 25.0
}
```

**返回字段（预测场景）**:
- `prediction`: `stable` 或 `unstable`
- `confidence`: 0-1 置信度
- `probabilities`: 每个类别概率
- `model_used`: 实际使用的模型名称（LightGBM 等）
- `recommendation`: 基于预测与置信度给出的文本建议

**返回字段（推荐场景）**: 当传入 `known_parameters` + `recommend_parameters` 时返回推荐字典，包括 `recommended`、`value_range`、`support_level`。

**错误响应**:

```json
{
  "error_code": "validation_failed",
  "message": "Parameter validation failed",
  "details": {
    "errors": [
      {
        "field": "pH",
        "code": "out_of_range",
        "expected": {"min": 0, "max": 14},
        "actual": 15
      }
    ]
  }
}
```

## 数据模型

### ExperimentInput (实验输入)

```typescript
{
  biomolecule_type: string;        // 必需: "protein" | "peptide" | "polysaccharide"
  biomolecule_name: string;         // 必需
  experiment_type: string;          // 可选，默认: "stability"
  pH?: number;                      // 可选: 0-14
  temperature_c?: number;           // 可选: -50 到 200
  concentration_mg_ml?: number;     // 可选: >0
  ionic_strength_mM?: number;       // 可选: >=0
  additive?: string;                // 可选
  time_min?: number;                // 可选: >=0
  shear_rate_s1?: number;           // 可选: >=0
  pressure_bar?: number;            // 可选: >=0
}
```

### ParameterPredictionRequest (参数预测请求)

```typescript
{
  input: ExperimentInput;
  predict_parameters: string[];    // 必需: 参数名数组
  top_k?: number;                    // 可选，默认: 3
}
```

### PredictRequest (`/api/v1/predict`)

```typescript
{
  biomolecule_name: string;
  biomolecule_type?: string;
  property: string;
  pH?: number;
  temperature_c?: number;
  concentration_mg_ml?: number;
  ionic_strength_mM?: number;
  additive?: string;
  time_min?: number;
  shear_rate_s1?: number;
  pressure_bar?: number;
  known_parameters?: Record<string, number>;
  recommend_parameters?: string[];
}
```

### JobCreateRequest (`/api/v1/jobs`)

```typescript
{
  task_type?: "predict";
  payload: Record<string, any>;
}
```

### JobStatusResponse

```typescript
{
  job_id: string;
  status: "PENDING" | "RUNNING" | "SUCCEEDED" | "FAILED";
  result_json?: Record<string, any>;
  result_url?: string | null;
  error?: string;
}
```

### UploadPayload (`/api/v1/upload`)

```typescript
{
  filename: string;
  content: string;                   // Base64 编码
}
```

### 参数校验规范

- 规范来源：`参数输入规范.md`
- 必填字段：`biomolecule_type`、`biomolecule_name`、`property`
- 至少提供 `settings.parameter_validation_optional_min_count` 个可选字段（默认 1 个）
- 校验失败将返回 `errors[{field, code, expected, actual}]` 及 `context`

## 错误处理

### HTTP状态码

- `200 OK`: 请求成功
- `201 Created`: 资源创建成功
- `202 Accepted`: 异步任务受理
- `400 Bad Request`: 请求参数错误
- `401 Unauthorized`: 未授权
- `404 Not Found`: 资源不存在
- `429 Too Many Requests`: 触发速率限制
- `500 Internal Server Error`: 服务器内部错误
- `503 Service Unavailable`: 模型或服务不可用

### 错误响应格式

```json
{
  "detail": "错误信息描述"
}
```

`/api/v1` 接口错误响应：

```json
{
  "error_code": "rate_limited",
  "message": "Rate limit exceeded",
  "details": {"retry_in_seconds": 10.5}
}
```

### 常见错误

#### 1. 参数验证错误 (400 / 422)

```json
{
  "error_code": "validation_failed",
  "message": "Parameter validation failed",
  "details": {
    "errors": [
      {
        "field": "biomolecule_type",
        "code": "missing",
        "message": "field required"
      }
    ]
  }
}
```

#### 2. 无效参数 (400)

```json
{
  "detail": "Invalid parameter: invalid_param. Valid values: ['pH', 'temperature_c', ...]"
}
```

#### 3. 预测失败 (500)

```json
{
  "detail": "Prediction failed: ML model loading error"
}
```

#### 4. 速率限制 (429)

```json
{
  "error_code": "rate_limited",
  "message": "Rate limit exceeded",
  "details": {"retry_in_seconds": 12.4}
}
```

## 常见问题

### Q1: 如何获取最相似的文献？

A: 两种方式：
1. 使用预测接口：`predict-classification` 或 `predict-parameter` 会自动返回 Top K 文献
2. 直接搜索：使用 `GET /literature/search` 接口

### Q2: 相似度算法是什么？

A: 使用加权欧氏距离算法，参数权重：
- pH: 25%
- Temperature: 20%
- Concentration: 20%
- Ionic strength: 15%
- Additive: 10%
- Time: 5%
- Shear rate: 3%
- Pressure: 2%

### Q3: 支持哪些生物分子类型？

A: 当前支持：
- `protein` - 蛋白质
- `peptide` - 多肽
- `polysaccharide` - 多糖

### Q4: 预测历史如何关联用户？

A: 当前版本中，如果提供了有效的 JWT Token，预测记录会关联到用户ID。匿名用户（无Token）的记录也会保存，但 `user_id` 为 `NULL`。

### Q5: 如何处理CORS错误？

A: 后端已配置CORS中间件，允许：
- `localhost` 和 `127.0.0.1`（任意端口）
- `192.168.x.x`（局域网IP）

如果需要添加其他域名，修改 `backend/app/main.py` 中的 CORS 配置。

### Q6: 模型文件在哪里？

A: ML模型文件应放在项目根目录的 `models/` 目录中。确保：
1. 模型文件存在
2. Docker volumes 正确挂载（见 `docker-compose.yml`）
3. 路径配置正确（默认 `models/` 目录）

### Q7: 数据库连接失败？

A: 检查：
1. MySQL容器是否运行：`docker compose ps`
2. 环境变量配置是否正确
3. 数据库是否存在：`appdb`
4. 端口映射是否正确（默认 53306 → 3306）

### Q8: 如何自定义参数校验规则？

A: 修改根目录《参数输入规范.md》，或设置环境变量 `PARAMETER_SPEC_PATH` 指向新的 Markdown 文件。服务会检测文件更新时间并自动重新加载。

### Q9: 异步任务和同步预测该怎么选择？

A: 实时小请求优先使用 `POST /api/v1/predict`。需要处理大型 CSV 或批量任务时，使用 `POST /api/v1/jobs` 创建任务并轮询 `GET /api/v1/jobs/{job_id}`，配合 `POST /api/v1/experiments/predict-csv` 完成批处理。

### Q10: 收到 `rate_limited` 时怎么办？

A: 表示触发速率限制（默认每分钟 120 次）。读取响应中的 `details.retry_in_seconds`，等待指定时间后再重试，并建议在客户端实现指数退避。

### Q11: CSV 上传遇到编码问题？

A: 系统默认尝试 `utf-8-sig`→`utf-8` 解码，若仍失败请先用 `iconv -f gbk -t utf-8 input.csv -o output.csv` 转换，再重新上传。
