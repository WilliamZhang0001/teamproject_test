## 概述

DoE-Assist 后端提供 RESTful API 接口，支持：
- 用户认证和管理
- 实验条件预测（分类判断和参数推荐）
- 文献检索和相似文献查找
- 用户实验历史记录

### 基础信息

- **API Base URL**: `http://localhost:8000`
- **API文档**: `http://localhost:8000/docs` (Swagger UI)
- **API文档(ReDoc)**: `http://localhost:8000/redoc`
- **协议**: HTTP/HTTPS
- **数据格式**: JSON

### 响应格式

所有API响应遵循统一格式：

```json
{
  "status": "success",
  "data": { ... }
}
```

错误响应：

```json
{
  "detail": "错误信息"
}
```

## 认证机制

### JWT Token 认证

系统使用 JWT (JSON Web Token) 进行用户认证。

### 1. 用户注册

**端点**: `POST /users`

**请求体**:
```json
{
  "username": "testuser",
  "email": "test@example.com",
  "password": "password123"
}
```

**响应** (201 Created):
```json
{
  "id": 1,
  "username": "testuser",
  "email": "test@example.com",
  "role": "user",
  "is_active": true,
  "created_at": "2024-01-01T00:00:00"
}
```

### 2. 用户登录

**端点**: `POST /auth/login`

**请求体**:
```json
{
  "username": "testuser",
  "password": "password123"
}
```

**响应** (200 OK):
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "user": {
    "id": 1,
    "username": "testuser",
    "email": "test@example.com",
    "role": "user",
    "is_active": true,
    "created_at": "2024-01-01T00:00:00",
```

在后续请求中，在Header中携带Token：

```

```

## API端点详细说明

### 1. 实验条件分类预测

**功能**: 判断输入的实验条件组合是好还是不好

**端点**: `POST /api/v1/experiments/predict-classification`

**请求参数**:
- `top_k` (Query, 可选): 返回最相似的文献数量，默认 3

**请求体**:
```json
{
  "biomolecule_type": "protein",
  "biomolecule_name": "lysozyme",
  "experiment_type": "stability",
  "pH": 7.0,
  "temperature_c": 25.0,
  "concentration_mg_ml": 10.0,
  "ionic_strength_mM": 150.0,
  "additive": "sucrose",
  "time_min": 60.0,
  "shear_rate_s1": 0.0,
  "pressure_bar": 1.0
}
```

**参数说明**:
- `biomolecule_type` (必需): 物质类别，可选值: `"protein"`, `"peptide"`, `"polysaccharide"`
- `biomolecule_name` (必需): 物质名称，如 `"lysozyme"`
- `experiment_type` (可选，默认: `"stability"`): 实验类别，可选值: `"stability"`, `"solubility"`, `"aggregation"`
- 以下8个参数均为可选（可提供任意组合）:
  - `pH`: pH值 (0-14)
  - `temperature_c`: 温度 (°C, -50 到 200)
  - `concentration_mg_ml`: 浓度 (mg/mL, >0)
  - `ionic_strength_mM`: 离子强度 (mM, >=0)
  - `additive`: 添加剂 (字符串)
  - `time_min`: 时间 (分钟, >=0)
  - `shear_rate_s1`: 剪切速率 (s⁻¹, >=0)
  - `pressure_bar`: 压力 (bar, >=0)

**响应** (200 OK):
```json
{
  "status": "success",
  "data": {
    "prediction": "Good",
    "confidence": 0.852,
    "similar_literature": [
      {
        "id": 1234,
        "similarity_score": 0.92,
        "literature": {
          "doi": "10.1234/example",
          "title": "Stability of lysozyme in...",
          "authors": "Smith, J. et al.",
          "pub_year": 2020
        },
        "parameters": {
          "pH": 7.0,
          "temperature_c": 25.0,
          "concentration_mg_ml": 10.0
        },
        "outcome_text": "Lysozyme remained stable...",
        "confidence": 0.85
      }
      // ... 最多返回 top_k 条记录
    ]
  }
}
```

**响应字段说明**:
- `prediction`: 预测结果，`"Good"` 或 `"Bad"`
- `confidence`: 置信度 (0-1)
- `similar_literature`: 最相似的文献列表（按相似度降序）
  - `similarity_score`: 相似度分数 (0-1)
  - `literature`: 文献元信息
  - `parameters`: 实验参数
  - `outcome_text`: 实验结果描述

### 2. 参数值预测

**功能**: 预测指定参数的值

**端点**: `POST /api/v1/experiments/predict-parameter`

**请求体**:
```json
{
  "input": {
    "biomolecule_type": "protein",
    "biomolecule_name": "lysozyme",
    "experiment_type": "stability",
    "pH": 7.0,
    "temperature_c": 25.0
  },
  "predict_parameters": ["concentration_mg_ml", "ionic_strength_mM"],
  "top_k": 3
}
```

**参数说明**:
- `input`: 用户输入的实验条件（格式同分类预测）
- `predict_parameters` (必需): 需要预测的参数列表，可选值:
  - `"pH"`
  - `"temperature_c"`
  - `"concentration_mg_ml"`
  - `"ionic_strength_mM"`
  - `"additive"`
  - `"time_min"`
  - `"shear_rate_s1"`
  - `"pressure_bar"`
- `top_k` (可选，默认: 3): 返回最相似的文献数量

**响应** (200 OK):
```json
{
  "status": "success",
  "data": {
    "predicted_parameters": {
      "concentration_mg_ml": {
        "recommended_value": 10.0,
        "min": 5.0,
        "max": 20.0,
        "median": 10.0
      },
      "ionic_strength_mM": {
        "recommended_value": 150.0,
        "min": 100.0,
        "max": 200.0,
        "median": 150.0
      }
    },
    "confidence": 0.75,
    "similar_literature": [
      {
        "id": 1234,
        "similarity_score": 0.88,
        "literature": { ... },
        "parameters": { ... }
      }
      // ... 最多返回 top_k 条记录
    ]
  }
}
```

**响应字段说明**:
- `predicted_parameters`: 每个参数的预测结果
  - `recommended_value`: 推荐值
  - `min`: 最小值（IQR范围）
  - `max`: 最大值（IQR范围）
  - `median`: 中位数
- `confidence`: 整体置信度 (0-1)
- `similar_literature`: 最相似的文献列表

**查询参数**:

```json
      "recommended_literature": [ ... ],
      "created_at": "2024-01-01T12:00:00"

```

### 4. 获取特定预测记录

**端点**: `GET /api/v1/experiments/{experiment_id}`

**路径参数**:

```json
{
  "status": "success",
```

### 5. 文献搜索

**功能**: 直接搜索相似的文献

**端点**: `GET /literature/search`

**查询参数**:
- `biomolecule_name` (可选): 生物分子名称
- `property_type` (可选，默认: `"stability"`): 属性类型
- `pH` (可选): pH值
- `temperature_c` (可选): 温度
- `concentration_mg_ml` (可选): 浓度
- `ionic_strength_mM` (可选): 离子强度
- `limit` (可选，默认: 3): 返回结果数量

**示例请求**:
```
GET /literature/search?biomolecule_name=lysozyme&pH=7.0&limit=3
```

```json
        "pub_year": 2020
      },
```

## 数据模型

### ExperimentInput (实验输入)

```typescript
{
  biomolecule_type: string;        // 必需: "protein" | "peptide" | "polysaccharide"
  biomolecule_name: string;         // 必需
  experiment_type: string;          // 可选，默认: "stability"
  pH?: number;                      // 可选: 0-14
  temperature_c?: number;           // 可选: -50 到 200
  concentration_mg_ml?: number;     // 可选: >0
  ionic_strength_mM?: number;       // 可选: >=0
  additive?: string;                // 可选
  time_min?: number;                // 可选: >=0
  shear_rate_s1?: number;           // 可选: >=0
  pressure_bar?: number;            // 可选: >=0
}
```

### ParameterPredictionRequest (参数预测请求)

```typescript
{
  input: ExperimentInput;
  predict_parameters: string[];    // 必需: 参数名数组
  top_k?: number;                    // 可选，默认: 3
}
```

## 错误处理

### HTTP状态码

- `200 OK`: 请求成功
- `201 Created`: 资源创建成功
- `400 Bad Request`: 请求参数错误
- `401 Unauthorized`: 未授权
- `404 Not Found`: 资源不存在
- `500 Internal Server Error`: 服务器内部错误

### 错误响应格式

```json
{
  "detail": "错误信息描述"
}
```

### 常见错误

#### 1. 参数验证错误 (400)

```json
{
  "detail": [
    {
      "loc": ["body", "biomolecule_type"],
      "msg": "field required",
      "type": "value_error.missing"
    }
  ]
}
```

#### 2. 无效参数 (400)

```json
{
  "detail": "Invalid parameter: invalid_param. Valid values: ['pH', 'temperature_c', ...]"
}
```

#### 3. 预测失败 (500)

```json
{
  "detail": "Prediction failed: ML model loading error"
}
```

## 示例代码

### Python 示例

```python
import requests

BASE_URL = "http://localhost:8000"

# 1. 用户注册
def register_user(username, email, password):
    response = requests.post(
        f"{BASE_URL}/users",
        json={
            "username": username,
            "email": email,
            "password": password
        }
    )
    return response.json()

# 2. 用户登录
def login(username, password):
    response = requests.post(
        f"{BASE_URL}/auth/login",
        json={
            "username": username,
            "password": password
        }
    )
    data = response.json()
    return data["access_token"]

# 3. 分类预测
def predict_classification(token=None):
    headers = {}
    if token:
        headers["Authorization"] = f"Bearer {token}"
    
    response = requests.post(
        f"{BASE_URL}/api/v1/experiments/predict-classification?top_k=3",
        json={
            "biomolecule_type": "protein",
            "biomolecule_name": "lysozyme",
            "experiment_type": "stability",
            "pH": 7.0,
            "temperature_c": 25.0,
            "concentration_mg_ml": 10.0
        },
        headers=headers
    )
    return response.json()

# 4. 参数预测
def predict_parameter(token=None):
    headers = {}
    if token:
        headers["Authorization"] = f"Bearer {token}"
    
    response = requests.post(
        f"{BASE_URL}/api/v1/experiments/predict-parameter",
        json={
            "input": {
                "biomolecule_type": "protein",
                "biomolecule_name": "lysozyme",
                "experiment_type": "stability",
                "pH": 7.0,
                "temperature_c": 25.0
            },
            "predict_parameters": ["concentration_mg_ml", "ionic_strength_mM"],
            "top_k": 3
        },
        headers=headers
    )
    return response.json()

# 使用示例
if __name__ == "__main__":
    # 注册和登录
    register_user("testuser", "test@example.com", "password123")
    token = login("testuser", "password123")
    
    # 预测
    result = predict_classification(token)
    print(result)
    
    result = predict_parameter(token)
    print(result)
```

## 常见问题

### Q1: 如何获取最相似的文献？

A: 两种方式：
1. 使用预测接口：`predict-classification` 或 `predict-parameter` 会自动返回 Top K 文献
2. 直接搜索：使用 `GET /literature/search` 接口

### Q2: 相似度算法是什么？

A: 使用加权欧氏距离算法，参数权重：
- pH: 25%
- Temperature: 20%
- Concentration: 20%
- Ionic strength: 15%
- Additive: 10%
- Time: 5%
- Shear rate: 3%
- Pressure: 2%

### Q3: 支持哪些生物分子类型？

A: 当前支持：
- `protein` - 蛋白质
- `peptide` - 多肽
- `polysaccharide` - 多糖

### Q4: 预测历史如何关联用户？

A: 当前版本中，如果提供了有效的 JWT Token，预测记录会关联到用户ID。匿名用户（无Token）的记录也会保存，但 `user_id` 为 `NULL`。

### Q5: 如何处理CORS错误？

A: 后端已配置CORS中间件，允许：
- `localhost` 和 `127.0.0.1`（任意端口）
- `192.168.x.x`（局域网IP）

如果需要添加其他域名，修改 `backend/app/main.py` 中的 CORS 配置。

### Q6: 模型文件在哪里？

A: ML模型文件应放在项目根目录的 `models/` 目录中。确保：
1. 模型文件存在
2. Docker volumes 正确挂载（见 `docker-compose.yml`）
3. 路径配置正确（默认 `models/` 目录）

### Q7: 数据库连接失败？

A: 检查：
1. MySQL容器是否运行：`docker compose ps`
2. 环境变量配置是否正确
3. 数据库是否存在：`appdb`
4. 端口映射是否正确（默认 53306 → 3306）
